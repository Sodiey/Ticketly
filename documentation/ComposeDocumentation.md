# Compose useful links

Here are the links to various Compose articles:

- [API Guidelines for Jetpack Compose](https://android.googlesource.com/platform/frameworks/support/+/androidx-main/compose/docs/compose-api-guidelines.md#naming-unit-composable-functions-as-entities)
  The Compose API guidelines outline the patterns, best practices and prescriptive style guidelines for writing idiomatic Jetpack Compose APIs.

- [API Guidelines for @Composable components in Jetpack Compose](https://android.googlesource.com/platform/frameworks/support/+/androidx-main/compose/docs/compose-component-api-guidelines.md)
  Set of guidelines and recommendations for building scalable and user-friendly @Composable components.

- [State and Jetpack Compose](https://developer.android.com/develop/ui/compose/state)
  This guide focuses on the connection between state and composables, and on the APIs that Jetpack Compose offers to work with state more easily.

- [Best Practices](https://developer.android.com/develop/ui/compose/performance/bestpractices)
  Best practices to optimize your app on Compose.

- [Where to hoist state](https://developer.android.com/develop/ui/compose/state-hoisting)
  This document showcase where you hoist UI state.

- [State holders and UI State](https://developer.android.com/topic/architecture/ui-layer/stateholders)
  This UI layer guide discusses unidirectional data flow (UDF) as a means of producing and managing the UI State for the UI layer.

Feel free to visit these links to gain valuable insight about good practices for working with Compose.
