PROMPTS.txt
============

This project was built with Claude Code (Anthropic's CLI coding agent) as a
collaborator across a long, multi-session conversation. What follows is a curated
selection of prompts from that session, lightly edited for clarity and grammar
while preserving the actual technical substance of each one, organized by theme,
focused on the parts that best show how the AI was actually used: setting
architecture direction, reviewing and pushing back on its output, catching real
bugs, and making explicit scope/tradeoff calls - not just accepting whatever it
produced.

------------------------------------------------------------

------------------------------------------------------------

"Apply clean architecture principles here, but don't over-engineer it. Implement
what's needed in EventsViewModel to fetch all the events from the backend - you
may need something in the repository layer, or possibly a use-case class; use
your judgment on that."

"Let's revisit DateChipsRow - the current approach feels hacky, and it only
covers a week. I want a proper implementation: the UI shows a few days at a
